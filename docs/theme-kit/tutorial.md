# راهنمای ساخت تم برای Chips

این راهنما برای دوستانی است که می‌خواهند برای Chips تم بسازند. کوتاه است: همه‌چیز
در چند دقیقه انجام می‌شود. فقط سه فایل لازم دارید:

- `starter.chipstheme` — قالب آماده با همهٔ رنگ‌ها و مقدارها
- `token-reference.md` — فهرست کامل توکن‌ها با نوع، محدوده و مقدار پیش‌فرض
- `ai-prompt.md` — متنی آماده که می‌توانید به هر چت‌بات هوش مصنوعی بدهید تا برایتان تم بسازد

> اسم توکن‌ها و مقدارها **انگلیسی** می‌ماند؛ فقط متن‌های راهنما فارسی است.

---

## ۱) فایل `.chipstheme` چیست؟

یک فایل `.chipstheme` فقط یک فایل **JSON** است. داخلش اسم تم، اسم سازنده، شمارهٔ
نسخهٔ قالب و یک دسته «توکن» (token) با مقدار دارد. توکن یعنی همان متغیرهای طراحی
که Chips استفاده می‌کند: رنگ صفحه، رنگ شیشه، شدت بلور، شعاع گوشه‌ها، فونت و
اندازهٔ متن.

فایل تم **فقط مقدار** می‌دهد. هیچ CSS، هیچ جاوااسکریپت، هیچ لینک و هیچ فونت یا
عکس بیرونی در آن نیست. برای همین نمی‌تواند به کامپیوتر شما کاری بدهد؛ فقط ظاهر
برنامه را عوض می‌کند.

یک نمونهٔ کوچک:

```json
{
  "format": "chipstheme",
  "version": 1,
  "name": "Midnight",
  "author": "Your name",
  "base": "glass",
  "tokens": {
    "color.accent": "#a74cfd",
    "glass.blur": 26,
    "font.family": "manrope"
  }
}
```

فقط همان چند توکنی را بنویسید که می‌خواهید عوض کنید؛ بقیه مقدار پیش‌فرض خودشان
را نگه می‌دارند.

---

## ۲) چطور تم را وارد (import) کنم؟

1. Chips را باز کنید.
2. روی **چرخ‌دندهٔ پایین صفحه** (کنار آواتار خودتان) بزنید تا تنظیمات باز شود.
3. بخش **Appearance** را انتخاب کنید.
4. پایین‌تر، زیر «Theme files»، روی **Import .chipstheme** بزنید و فایل را انتخاب
   کنید.

اگر فایل درست باشد، همان لحظه اعمال می‌شود، در فهرست تم‌ها کنار چهار تم آمادهٔ
Liquid Glass می‌نشیند و بعد از بستن و باز کردن برنامه هم یادش می‌ماند.

اگر فایل ایراد داشته باشد، **هیچ چیز عوض نمی‌شود**؛ فقط یک پیام انگلیسی نشان
داده می‌شود که می‌گوید کدام خط مشکل دارد (مثلاً JSON خراب، نسخهٔ اشتباه، اسم
توکن ناشناخته، یا مقدار خارج از محدوده).

---

## ۳) چطور تم خودم را بسازم؟

1. `starter.chipstheme` را با یک ویرایشگر متن باز کنید (Notepad هم کافی است).
2. مقدار `name` و `author` را عوض کنید.
3. یکی از توکن‌ها را تغییر دهید — مثلاً:

   ```json
   "color.accent": "#fd1d1d"
   ```

4. فایل را با پسوند `.chipstheme` ذخیره کنید (مثلاً `my-theme.chipstheme`). حتماً
   UTF-8 باشد.
5. همان‌طور که در بخش ۲ گفتیم import کنید.
6. اگر جایی اشتباه کردید، فایل را دوباره ویرایش و import کنید؛ نسخهٔ قبلی همان
   تم را جایگزین می‌کند.

**نکتهٔ مهم:** ویرگول آخر در JSON مجاز نیست. هر خط `"کلید": "مقدار"` است و بین
خط‌ها ویرگول می‌آید، ولی خط آخرِ هر بلوک ویرگول ندارد. اگر JSON خراب باشد، Chips
فایل را قبول نمی‌کند و دلیلش را می‌گوید.

---

## ۴) هر توکن چه کاری می‌کند؟

فهرست کامل با نوع و محدوده در `token-reference.md` است. خلاصهٔ گروه‌ها:

| گروه | توکن‌ها | کار |
| --- | --- | --- |
| رنگ صفحه | `color.page`، `color.pageDeep` | پس‌زمینهٔ برنامه و انتهای تاریک‌ترش. تم پیش‌فرض `#05050a` است. |
| شیشه | `color.surface`، `color.surfaceStrong`، `color.surfaceHover`، `color.surfacePress`، `color.surfaceSunken` | شفافیت و تُن پنل‌ها، نوارها و کارت‌ها. |
| نور لبه | `color.edge`، `color.edgeSoft`، `color.depth` | خط باریک روشن روی لبهٔ بالای پنل‌ها و سایهٔ نرم داخلی. این تنها «نور» تم است. |
| لهجه (accent) | `color.accent`، `color.accentContrast` | رنگ اصلی برنامه (پیش‌فرض `#74e5ff`) و رنگ متن روی آن. پنجره، تیک، لینک و هایلایت‌ها از این رنگ ساخته می‌شوند. |
| متن | `color.text`، `color.textMuted`، `color.textFaint`، `color.clientText` | متن اصلی، متن دوم، راهنماها و اسم کاربران در درخت کانال. |
| وضعیت | `color.success`، `color.danger` | رنگ موفقیت و رنگ خطا. |
| کنترل‌ها | `color.border`، `color.borderSoft`، `color.input`، `color.button`، `color.buttonAlt`، `color.buttonHover`، `color.buttonHoverAlt`، `color.rowHover` | خط‌ها، کادر ورودی، دکمه‌ها و هاور ردیف‌ها. |
| لاگ | `color.logBackground`، `color.badge`، `color.toolbar`، `color.toolbarAlt` | نوار لاگ، نشان نسخه و دو متغیر قدیمی نوار ابزار. |
| شیشه (اندازه) | `glass.blur`، `glass.saturate`، `glass.radius`، `controls.radius` | شدت بلور (۰ تا ۶۰)، اشباع رنگ (۱۰۰ تا ۲۵۰)، شعاع گوشهٔ کارت‌ها و دکمه‌ها. |
| فونت | `font.family`، `font.size` | فقط فونت‌های همراه خود برنامه: `plus-jakarta-sans`، `manrope`، `vazirmatn`، `vt323`. اندازه ۱۱ تا ۱۸. |

چند توصیهٔ عملی:

- برای تم تیره، `color.surface` را با آلفای کم نگه دارید (مثلاً
  `rgba(255, 255, 255, 0.05)`) تا شیشه‌ای بماند.
- اگر `color.accent` را روشن کردید، `color.accentContrast` را تیره بگذارید؛ اگر
  تیره شد، روشن. (اگر ننویسید، Chips خودش حساب می‌کند.)
- برای ظاهر «Subtle» مثل خود برنامه: `glass.blur` را ۱۰ و `glass.saturate` را ۱۲۰
  بگذارید. اگر شیشه نمی‌خواهید، `glass.blur` را صفر کنید.
- اگر فونت `vt323` را انتخاب کردید، اندازهٔ ۱۴ یا ۱۵ خواناتر است.

---

## ۵) قواعد ایمنی

1. فقط توکن. هر چیز دیگری (CSS، اسکریپت، لینک، فونت یا عکس بیرونی، `text-shadow`،
   glow) رد می‌شود.
2. توکن ناشناخته خطاست؛ یعنی اگر اسم را اشتباه بنویسید، خطا می‌گیرید و می‌فهمید.
3. مقدارها باید در محدوده باشند؛ `glass.blur` بیشتر از ۶۰ پذیرفته نمی‌شود.
4. عددها را بدون کوتیشن و بدون واحد بنویسید: `"glass.blur": 24` (نه `"24px"`).
5. نسخه (`version`) باید `1` باشد و `base` باید `"glass"`.
6. فایل تم نمی‌تواند چیزی را پنهان کند، صدایی پخش کند یا کاری در برنامه انجام
   دهد؛ فقط رنگ و اندازه است.

هیچ توکنی برای درخشش (glow) وجود ندارد و اضافه هم نمی‌شود. نور در Chips همان خط
باریک و تیز لبهٔ شیشه است.

---

## ۶) چطور تم را export کنم و با دیگران شریک شوم؟

1. تنظیمات → **Appearance** → زیر «Theme files».
2. روی **Export current look** بزنید.
3. اسم تم و اسم خودتان (author) را بنویسید و **Save** بزنید.

فایلی با پسوند `.chipstheme` ذخیره می‌شود که همان ظاهری را توصیف می‌کند که
همان لحظه روی صفحه دارید — چه یکی از تم‌های آماده، چه یک تم واردشده. همین فایل را
می‌توانید برای دوستتان بفرستید؛ او هم با Import آن را اضافه می‌کند.

تم‌های آماده (چهار رنگ Liquid Glass) حذف‌شدنی نیستند؛ تم‌هایی که خودتان import
کرده‌اید با دکمهٔ سطل آشغال کنارشان قابل حذف‌اند.

---

## ۷) با هوش مصنوعی تم بسازم؟

فایل `ai-prompt.md` را باز کنید، متنش را کامل کپی کنید و به چت‌بات بدهید. آخر
همان متن، حال‌وهوایی که می‌خواهید را بنویسید (مثلاً «تم سرد و آرام با آبی
یخی»). چت‌بات یک JSON کامل برمی‌گرداند؛ آن را در فایلی با پسوند `.chipstheme`
ذخیره و import کنید. اگر چیزی را اشتباه داد، پیام خطای Chips دقیقاً می‌گوید کجا
را باید درست کند.

خوش بگذرد — و اگر تم قشنگی ساختید، برای بقیه هم بفرستید.
